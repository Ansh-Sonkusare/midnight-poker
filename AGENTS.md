## Agent skills

### Issue tracker

Issues live as GitHub issues on `github.com/Ansh-Sonkusare/midnight-poker`. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical labels with default names (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context repo. One `CONTEXT.md` at root + `docs/adr/` for architectural decisions. See `docs/agents/domain.md`.
