# Platform generates deck via trusted setup ceremony instead of multi-party mental poker

Fully trustless poker would require each player to jointly generate the deck via a multi-party shuffle protocol (each permutes, signs a ZK proof of their permutation, passes to next). This is significantly more complex — more on-chain transactions per hand, more witness functions, and harder UX (all players must be online simultaneously for deck generation). A trusted setup ceremony where the platform generates the deck + ZK shuffle proof is simpler to implement and still cryptographically constrains the platform (it cannot modify the deck mid-hand without breaking the proof). Post-game anyone verifies all reveals against the commitments. Acceptable trade-off: the platform could in theory know a player's hole cards, but the contract code and the shuffle proof ensure fair play.
